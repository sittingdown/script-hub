# Script Hub

A plugin-based automation launcher for FiveM. Download, run, and keep everything up to date from one place.

---

## Installation

1. Go to [Releases](https://github.com/sittingdown/script-hub/releases/latest) and download `hub.exe`
2. Create a folder anywhere and place `hub.exe` inside it
3. Download the `plugins` folder from this repo and place it next to `hub.exe`

Your folder should look like this:
```
hub.exe
plugins/
  magnet_bot.py
  key_spammer.py
  weed_bagging.py
```

4. Run `hub.exe`

---

## Plugins

| Plugin | Description |
|--------|-------------|
| **Magnet Bot** | Automated fishing minigame bot. Scans for colored targets and auto-clicks. |
| **Key Spammer** | Spams E → W → A on repeat. Auto-pauses when FiveM loses focus. |
| **Weed Bagging** | Spams a key sequence for the weed bagging job. Auto-pauses when FiveM loses focus. |

---

## Updating

**Plugins** — click **Update Plugins** on the hub home screen. Downloads the latest plugin files from GitHub and reloads automatically. No restart needed.

**Hub exe** — when a new version is available, a banner will appear on the home screen with a download link.

---

## Requirements

- Windows 10 / 11
- FiveM running on the same machine

No Python installation needed — everything is bundled in the exe.
